# CANOPY project page

Static project page for *CANOPY: Adaptive-Granularity Evidence Compression for Multimodal RAG*.

- `index.html` — the whole page (inline CSS, no build step)
- `static/images/` — figures rendered from the paper's PDF figures

Served at `https://canopy-project-page.github.io/` by GitHub Pages from branch `main`, folder `/`. The paper is arXiv:2610.00923.
